# Famous plots (docs/design/research.md, Part 3): one block per figure.
# Build the data first: python make_data.py; then: plotipus run famous
#
# The commands use only what plotipus does today, plus the project plugin
# annotations.py (--text, drawn by a figure hook). Recurring tricks:
# - data points and model lines in one figure: --style on the same column
#   with --comparable_linestyles none solid ..., --plot_type line --errory
#   --errory_type bars (data keep their error bars, models have none);
# - a band in its own colour: a row of its own drawn with linewidth 0
#   (--comparable_linewidths);
# - fitted straight lines: rows whose end points lie outside --rangex, so
#   --plot_type plot clips their markers.
# "# gap:" lines name what is still missing and the task it belongs to.
