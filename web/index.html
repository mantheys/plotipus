Publication plots and tables, one command each

plotipus draws pickled pandas DataFrames. Analysis code writes its results once, one row per series with whole arrays in the cells, and every figure and LaTeX table is redrawn from them with a plain-text command: no plotting scripts to maintain, and the same look in every figure. 

plotipus line --datafile Distributions -x Bin -y Counts --hue Sample --data_hue Data --lower ratio
plotipus run paper          # every command in input/plots/paper_scripts.txt

Produce the data once, plot it without limits

A well-built DataFrame is all you ever need to save: it is your immutable source, and every figure and table is redrawn from it.

Journal styles, experiment-wide conventions and collaboration rules are a style file or a plugin away, without touching your analysis.

What one command draws

line

Data against simulation, with the ratio. --data_hue marks the measured rows: they become ink points with error bars, the simulation a step histogram with its band, and --lower ratio adds the panel below.

line

Fits stored with the data. The DataFrame carries the fit function and its parameters; --fit --lower pull draws the curve, its components, the parameter legend and the pulls.

map

Maps, contours and corner plots. 2D histograms, hexbins and Δχ² grids with their confidence regions; --corner draws every pair of variables on one shared colour scale.

famous

Flexible enough for the classics. The Higgs discovery plots, the Keeling curve and Hubble's 1929 diagram are redrawn from public data, each with a single command.

styles

One command list, every medium. Slides, a paper column or the web, light or dark: the commands do not change, only the size, the type and the colours do.

From a DataFrame to a figure

Three steps: save a DataFrame, write a command, keep the command in a list. Everything else (colours, sizes, error bars, legends) follows from the data and the style.

1 Install

pipx install git+https://github.com/mantheys/plotipus.git
plotipus init my_project

Python ≥ 3.10. init creates plotipus.toml, input/{data,plots,tables} and output/.

2 Try the examples

git clone https://github.com/mantheys/plotipus.git
cd plotipus/examples
python make_data.py      # toy pickles
plotipus run example     # figures in output/plots

--tables writes the LaTeX tables instead.

Your own data

3 One row per series, arrays in the cells

plotipus reads pickled (or Parquet) DataFrames from input/data/: --datafile Spectrum loads input/data/Spectrum.pkl.

import numpy as np
import pandas as pd

x = np.arange(0.25, 10, 0.5)                     # bin centres (GeV)
expected = 200 * np.exp(-x / 3)                  # the simulation's prediction
observed = np.random.default_rng(1).poisson(expected)

pd.DataFrame([
    {"Sample": "Simulation", "Energy": x, "Counts": expected, "CountsError": 0.05 * expected},
    {"Sample": "Data",       "Energy": x, "Counts": observed},
]).to_pickle("input/data/Spectrum.pkl")

plotipus line --datafile Spectrum -x Energy -y Counts --hue Sample --data_hue Data --errory --lower ratio
  • -x, -y name the columns to draw; --hue names the column that splits the rows into series, one colour each; --data_hue Data marks the data rows, drawn as points.
  • Errors live next to the value: {y}Error, or {y}Error+ and {y}Error-. A row without them gets the standard interval where one applies: counts get Poisson (Garwood) intervals.
  • Commands go one per line in input/plots/<name>_scripts.txt, and plotipus run <name> draws them all.

Plot kinds

Kinds follow the data relationship, as in seaborn and plotly, not the use case. plotipus <kind> --help lists every option.

KindDrawsTypical options
liney against an ordered x, one series per --hue value --plot_type, --data_hue, --lower, --stacked, --fit, --binned, --facet_row, --inset
scatterobservations with colour, size and marker encodings --colorby, --sizeby, --markerby
hist1D histograms of per-event arrays, KDEs, ECDFs --bins, --weight, --density, --hist_type kde|ecdf, --ridge
map2D histograms, hexbins, corner plots, images of a grid, contours --norm, --logz, --map_type hexbin, --corner, --contour
catone value per category --kind point|line|lollipop|bar|box|violin|strip, --orient h, --sort
tableaggregated values as LaTeX and HTML tables --variables, --agg, --stats, --fit_params, --cutflow, --siunitx

Every kind takes annotations (--text, --arrow, --region), reference lines and bands, and writes PNG at 300 dpi or, with --format pdf, vector output at the printed size.

One command list, every medium

A style combines a design language, a medium and a theme. Figures are drawn at the size they are shown at, so text is never scaled to fit: slides first, then a paper column or the web, with no change to the commands. File names stay the same in every folder, so a LaTeX \includegraphics only changes its directory.

plotipus run analysis --theme dark     # output/plots/slides-dark/

Experiment headers and watermarks

A header and a status on every figure. --experiment atlas|cms|lhcb|alice|dune applies the experiment's label, typography and palette; --label_status and --watermark mark work in progress. Set them once in plotipus.toml:

[header]
experiment = "dune"
label_status = "Preliminary"
label_right = "1.2 MW, 10 years"
watermark = "preliminary"
watermark_style = "diagonal"

The style guide

The defaults are not taste: each one applies a rule of the style guide.

  • The kind of a series decides how it is drawn. Data, simulation, fits and theory each have one look, the same in every plot.
  • A figure has a fixed printed size per medium. Text is never scaled to fit; layouts add or share space instead.
  • Every number carries its uncertainty, computed by the method that suits the quantity, and says which method it is.
  • No silent guesses. When plotipus fills in something the data did not give, it prints a warning that names what it did and how to change it.
  • Conventions live in the data. A DataFrame that follows the column conventions needs no options to be drawn right.
  • One command list, every medium. A category keeps its colour and a series its look across slides, paper and web.

Famous plots, redrawn

Famous figures from particle physics, cosmology, astronomy and climate science, redrawn by plotipus in the paper style. The commands aim at the originals (their colours, line styles, markers, legend layout and annotations) to show that plotipus can draw what others drew.

real data comes from public data releases; extracted values were read back from the vector graphics of the published figures. Data, commands and remaining gaps: examples/famous.

cd examples/famous
python make_data.py            # 22 pickles in input/data
plotipus run famous            # figures in output/plots

Recreations made to demonstrate plotipus, not the original figures or official results of the ATLAS, CMS, LEP, KamLAND or Gaia collaborations or of the original authors, who do not endorse this project: cite the originals, linked from each figure.
