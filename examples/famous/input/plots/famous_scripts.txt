# Famous plots (docs/design/research.md, Part 3): one block per figure.
# Build the data first: python make_data.py; then: plotipus run famous
#
# The commands use only what plotipus does today, plus the project plugin
# annotations.py (--text, drawn by a figure hook). Recurring patterns:
# - data and models in one figure: --data_hue for the measured series
#   (points with error bars) and --plot_type line for the models; with
#   --style on the hue column, --comparable_linestyles (and --comparable_linewidths)
#   are matched to the hue order (the key order of --iterable_color_mapping);
#   --series_marker gives single series their marker;
# - per-series line widths from the Width column (--linewidth_column); a band
#   in its own colour is a row of its own with Width 0;
# - fitted straight lines are rows that end outside --rangex.
# Experiment headers carry "recreation" (--label_status): these are not
# official ATLAS or CMS plots.
# The figures aim at the originals (colours, line styles, legend layout,
# annotations); the restyled versions belong in docs/styleguide.md.
# Common gap: per-figure fonts and rcParams (sans or Times text, bold labels,
# a coloured frame) -> follow-up (a per-command style file); the paper font
# cmr10 has no bold face, so --text_weight bold has no effect.
# "# gap:" lines name what is still missing and the task it belongs to.
